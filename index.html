INDIVIDUAL PROJECT • FULL STACK

AgroConnect 2.0

Problem: An agricultural marketplace is not useful if anyone can claim to be a farmer, users cannot trust sellers, or the system ignores delivery, payments and role-specific workflows.

I built AgroConnect 2.0 as a multi-role agricultural marketplace connecting buyers, farmers, fertilizer sellers, delivery partners, verification employees and administrators.

  • Farmer verification workflow with supporting farm evidence, location and manual review.
  • Unverified farmers are restricted from publishing produce.
  • Role-based authentication, dashboards and protected workflows.
  • Cart, orders, delivery, notifications and payment flows.
  • React + Vite frontend, Node.js + Express backend and MongoDB.
  • Socket.IO realtime features, Cloudinary uploads, CI/CD and deployment work.
